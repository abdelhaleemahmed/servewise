servewise

A safe local preview server for built static sites — Hugo, Sphinx, Jekyll, MkDocs, plain HTML. It's python -m http.server with the four things that bite you during a real preview fixed.

One file, no dependencies. Prints exactly what it serves and where.

Four things http.server doesn't do

1Caching disabled

Every response sends Cache-Control: no-store, so an edited stylesheet or script shows on an ordinary reload — no more "is it cached or broken?"

2First free port from 8000

No "address already in use", and — crucially — no two servers silently sharing a port. The chosen port is printed.

3It says who it is

Each instance answers GET /__serve_info with its version, file path, hash, root, and pid — so one copy can ask another what it is.

4It checks its own version

At startup and on --check, it compares itself by version and content hash against the canonical copy and every running instance, flagging drift.

The bug that made port safety non-negotiable

The obvious way to pick a port is "try to bind, catch the failure, try the next." On Windows there is no failure to catch.

Two servers, one port, wrong site — silently

Windows honours SO_REUSEADDR, so a second process can bind a port that is already being listened on. It happened here: two servers both bound to 8000, and a request returned 200 with the right no-store header — while serving the wrong site. Nothing failed, nothing logged. Only comparing the response body caught it.

So servewise probes the port with an outbound connection before binding — the same behaviour on every platform. A socket in TIME_WAIT refuses the probe, so an immediate restart still works.

Usage

servewiseFirst free port from 8000; serves the nearest built site (walks up to the closest index.html).
servewise 8010Start the port search at 8010.
servewise --strict 8010Use exactly 8010, or fail — don't wander to another port.
servewise --root DIRServe some other directory.
servewise --checkAudit versions across copies and running instances, then exit.
python -m servewiseSame as the servewise command; the single file runs as python server.py.

Requires Python 3.8+ and nothing else — it is standard library only.
